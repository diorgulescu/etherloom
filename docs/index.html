Multi-OS Virtual Networks on macOS.
Every Wire Tappable. Zero Root Required.

Etherloom is a native macOS network orchestration, packet-capture, and learning studio built with Tauri v2 (Rust + Tokio) and React 19. Boot hardware-accelerated and multi-arch topologies across 15 curated Linux, BSD, Enterprise Router/Firewall, Plan 9, Illumos, and Retro DOS operating systems alongside zero-VM Host NAT Internet Gateways, Dual-Stack DHCPv4/v6 Servers, and 802.1D L2 Switches — then stream virtual cables live into Wireshark or dissect TCP flows visually inside the app with tcpflowy.

System Design & Recent Additions

Zero-Root macOS Virtualization & Userspace Packet Fabric

Every QEMU hypervisor instance, virtual switch, DHCP/NAT appliance, serial console, and wiretap runs strictly under your standard macOS user account — zero sudo, zero chmod /dev/bpf*, zero vmnet daemons, and zero kernel extensions.

Zero-Root Data Plane — Raw Ethernet II over Loopback UDP + In-Process Appliances + Atomic Wiretaps 802.1Q • 9216B Jumbo Ready

UDP PacketFabric 802.1Q + Jumbo

QEMU NICs attach via -netdev socket,udp=127.0.0.1:... exchanging raw Ethernet II frames (up to 9,216-byte jumbo & double-tagged 0x8100 VLAN frames) across point-to-point wires, inspectable 802.1D L2 Switches, and L1 Hubs with live RTT, jitter, loss, and cable-cut controls.

Host NAT Gateway Zero-Root WAN

Built-in Rust nat_gateway appliance translates guest IPv4 (NAT44), IPv6 (NAT66), TCP, UDP, DNS (:53 proxy), and ICMP/ICMPv6 ping flows over unprivileged macOS sockets — with WAN DHCP auto-config, live NAT session tables, and full packet capture on the WAN wire.

Dual-Stack DHCP Appliance v4 + v6 + RA

Zero-VM dhcp_server appliance directly on PacketFabric answering ARP, ICMPv4/v6 echo, DHCPv4 DORA (UDP 67/68), ICMPv6 Router Solicitations (SLAAC A=1 + RDNSS Option 25), and stateful DHCPv6 IA_NA (UDP 546/547) with live lease inspection.

Multi-Arch QEMU & Floating Dock 4 Archs

Runs native -accel hvf plus multi-threaded TCG across aarch64, x86_64, i386, and riscv64 with 5 NIC models (virtio-net, e1000, rtl8139, pcnet, ne2k_pci), paired with a detachable, moveable, 8-way resizable xterm.js + noVNC console dock.

Node Activity Monitor ⌘⇧M

Native macOS telemetry dialog sampling proc_pid_rusage physical memory footprint (ri_phys_footprint), RSS, guest CPU %, thread counts, CoW .qcow2 disk read/write bytes, rolling sparklines, and expandable per-NIC RX/TX packet & byte rates.

External SSD & Security Hardening Hardened

Streams downloads in .staging/ on APFS/ExFAT /Volumes SSDs with fail-closed SHA-256 & zip-slip checks, confines shared .etherloom bundle paths, validates loopback WebSocket Host/Origin headers under a strict CSP, and guards QEMU kills via KERN_PROCARGS2.

Deep Packet & Flow Visibility

One-Click Wiretaps, Atomic PCAP Export & Integrated tcpflowy

Click or right-click any virtual cable to start a live REC MM:SS capture alongside independent mkfifo Live Wireshark streaming. Stopping a capture atomically drains queued frames, flushes buffers, and fsyncs <nodeA>-<nicA>__<nodeB>-<nicB>__<timestamp>.pcap with zero packet truncation.

Capture Workflow One-Click Action Zero-Root Behavior
Live Stream Live Wireshark (FIFO) Streams real-time LINKTYPE_ETHERNET frames into Wireshark.app over /tmp/etherloom/tap_<link>.pcap while .pcap file recording continues uninterrupted.
Stop & Export Stop & Save PCAP… Atomically flushes & fsyncs the capture in <project>.etherloom/captures/, opens a native macOS Save dialog, and offers a 1-click Reveal in Finder action.
Stop & Inspect Stop & Open in Wireshark Finalizes the .pcap with zero truncation and opens Wireshark.app in static read mode (-r <pcap_path>).
Stop & Dissect Stop & Dissect (tcpflowy) Finalizes the .pcap and immediately dissects TCP conversations inside the Bottom Dock via tcpflowy.
Captures History Dissect / Wireshark / Save Copy As… / Finder Re-dissect any historical workspace capture, import external .pcap/.pcapng files, export copies anywhere on macOS, or reveal in Finder (open -R).

Interactive Networking Academy

Eight Built-in Multi-OS Guided Labs

Each lab instantiates a clean sandbox workspace (academy-<id>.etherloom), checks OS Library prerequisites with 1-click filtered download handoffs, illuminates target wires on the canvas, and pairs Markdown protocol diagrams with Send to Serial command blocks.

01 • Hubs, Switches & ARP

Compare L1 Hub broadcast flooding against IEEE 802.1D L2 Switch MAC learning and inspect broadcast ARP requests vs. unicast ARP replies.

02 • Subnetting & Static Routing

Connect two /24 subnets through a multi-homed Linux router, enable IPv4 forwarding, configure static routes, and verify TTL decrements.

03 • OpenBSD pf & Stateful NAT

Author a clean /etc/pf.conf with default-deny filtering and nat-to masquerading, then compare LAN vs. WAN captures in tcpflowy.

04 • OpenBSD CARP + pfsync HA

Build an Active/Backup OpenBSD firewall cluster sharing a virtual IP (vhid 1) with live state synchronization and cut the primary wire mid-session.

05 • TCP Handshakes, Window & Loss

Run transfers across a pre-impaired WAN wire (80 ms latency, 5% packet loss) to observe window scaling, fast retransmit, and RTO backoff.

06 • FreeDOS + mTCP Zero-Noise TCP

Boot 32-bit FreeDOS (PCNTPK 0x60 + mTCP) against an IPv6-quieted Alpine responder to capture the exact 4 frames of ARP+ICMP and pure TCP byte math.

07 • OpenWrt 802.1Q VLANs & fw4

Configure modern UCI bridge-vlan / DSA filtering, capture double-tagged 0x8100 frames on a trunk wire, and enforce nftables zone isolation.

08 • MikroTik CHR v7 ↔ OpenBSD eBGP

Establish RFC 8212 eBGP peering over TCP/179 between RouterOS v7 and OpenBGPD, dissect OPEN/UPDATE/KEEPALIVE, and test live cable-cut failover.

System Requirements

Designed for Apple Silicon and Intel Macs running unprivileged in standard userspace — with first-class external USB-C / Thunderbolt SSD offload.
