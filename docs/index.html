Etherloom is a native macOS network orchestration and learning studio built with Tauri v2 (Rust + Tokio) and React 19. Boot hardware-accelerated Alpine Linux, OpenBSD, FreeBSD, and NetBSD topologies via Apple’s Hypervisor.framework, inject live packet loss and latency, stream virtual cables into Wireshark, and visually dissect TCP flows inside the app with tcpflowy.

System Design

Zero-Root macOS Virtualization Architecture

Every QEMU process, virtual switch, serial console, and packet capture runs strictly under your unprivileged macOS user account — no sudo, no chmod /dev/bpf*, and no kernel extensions.

UDP Datagram PacketFabric

QEMU NICs attach via -netdev socket,udp=127.0.0.1:... transmitting raw IEEE 802.3 Ethernet II frames per UDP datagram (no 4-byte TCP length prefix). Tokio routes frames across point-to-point wires, IEEE 802.1D learning L2 Switches, and L1 Hubs while enforcing live latency, jitter, loss, and cable-cut impairments.

Dual Serial + UEFI VNC Consoles

Every ARM64 VM boots with Homebrew’s edk2-aarch64-code.fd UEFI firmware and exposes both an unbuffered PL011 Unix serial console (rendered in @xterm/xterm for pfctl, tmux, and vi) and an embedded ramfb graphical screen via @novnc/novnc.

External SSD Resilience (/Volumes)

Keep multi-gigabyte ISOs, read-only Golden Templates, and project overlays on Thunderbolt/USB-C drives (APFS or ExFAT) while sockets, FIFOs, and Python symlinks stay safely on local storage. Includes a st_dev mount guard and automatic qemu-img rebase -u portability.

Managed Python Virtualenv Bridge

Interactive Networking Academy

Eight Built-in Multi-OS Guided Labs

Each lab instantiates a clean sandbox workspace (academy-<id>.etherloom), checks OS Library prerequisites with 1-click download handoffs, highlights target wires on the canvas, and pairs Markdown protocol diagrams with Send to Serial commands.

01 • Hubs, Switches & ARP

Compare L1 Hub broadcast flooding against IEEE 802.1D L2 Switch MAC learning and inspect broadcast ARP requests vs. unicast ARP replies.

02 • Subnetting & Static Routing

Connect two /24 subnets through a multi-homed Linux router, enable IPv4 forwarding, configure static routes, and verify TTL decrements.

03 • OpenBSD pf & Stateful NAT

Author a clean /etc/pf.conf with default-deny filtering and nat-to masquerading, then compare LAN vs. WAN captures in tcpflowy.

04 • OpenBSD CARP + pfsync HA

Build an Active/Backup OpenBSD firewall cluster sharing a virtual IP (vhid 1) with live state synchronization and cut the primary wire mid-session.

05 • TCP Handshakes, Window & Loss

Run transfers across a pre-impaired WAN wire (80 ms latency, 5% packet loss) to observe window scaling, fast retransmit, and RTO backoff.

06 • FreeDOS + mTCP Zero-Noise TCP

Boot 32-bit FreeDOS (PCNTPK 0x60 + mTCP) against an IPv6-quieted Alpine responder to capture the exact 4 frames of ARP+ICMP and pure TCP byte math.

07 • OpenWrt 802.1Q VLANs & fw4

Configure modern UCI bridge-vlan / DSA filtering, capture double-tagged 0x8100 frames on a trunk wire, and enforce nftables zone isolation.

08 • MikroTik CHR v7 ↔ OpenBSD eBGP

Establish RFC 8212 eBGP peering over TCP/179 between RouterOS v7 and OpenBGPD, dissect OPEN/UPDATE/KEEPALIVE, and test live cable-cut failover.

Custom Declarative Labs

Author new tutorials with just two plain-text files — lab.toml + guide.md — inside labs/ or your external storage library.
